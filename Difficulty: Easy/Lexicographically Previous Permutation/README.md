<h2><a href="https://www.geeksforgeeks.org/problems/lexicographically-previous-permutation3620/1">Lexicographically Previous Permutation</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given a string <strong>s</strong> representing a non-negative integer, find the lexicographically previous permutation of its digits. Each digit of s must be used exactly once, and the resulting number must not contain leading zeros.</span></p>
<ul>
<li><span style="font-size: 14pt;">If no previous permutation exists, return "-1".</span></li>
<li><span style="font-size: 14pt;">The answer should be returned as a string.</span></li>
</ul>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input</strong>: s = "4321"
<strong>Output:</strong> "4312" 
<strong>Explanation</strong>:The lexicographically previous permutation of "4321" is "4312".</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>s =<strong> </strong>"1234"
<strong>Output: </strong>"-1"
<strong>Explanation</strong>: The string "1234" is sorted in ascending order, so no previous permutation exists. </span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 ≤ |s|&nbsp;≤ 10^5<br></span><span style="font-size: 18px;"><span style="font-size: 18px;">where |s| denote the lengths of the strings.</span></span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Strings</code>&nbsp;<code>permutation</code>&nbsp;
